# ✅ المهام (Tasks)

بطاقات مهام **مفهرسة**: كل بطاقة مؤشّر خفيف يربط مهمّة بمرحلة + معلم + مستودع + مسؤول + RFC.

> **مبدأ:** البطاقة **لا تنسخ** تفاصيل التنفيذ. الحقيقة (الكود، القصّة، معايير القبول التفصيليّة)
> تعيش في مستودع المنتج (ستوري `STORY-*` أو RFC). البطاقة تشير إليها فقط — لمنع التباعد (GR-01).

## شروط البطاقة الصحيحة (يفرضها المدقّق)
- مرتبطة بـ**مرحلة** موجودة (وهي المرحلة المفتوحة، لا لاحقة).
- مرتبطة بـ**معلم** موجود.
- تمسّ **مستودعًا واحدًا** له فريق.
- لها **مسؤول** و**RFC** (قفل).
- قابلة للإنهاء خلال **2–5 أيام** (تجاوزت أسبوعًا؟ قسّمها — قاعدة 5).
- لها **DoD** قابل للقياس بدليل.

## الحالات المسموحة
`todo` → `in-progress` → `review` → `done` (أو `blocked` مع سبب).

انسخ [_TEMPLATE.md](_TEMPLATE.md) إلى `TASK-XXXX-<slug>.md` (رقم تسلسليّ من 4 خانات).
