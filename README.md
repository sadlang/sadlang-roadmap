# 🧠 sadlang-roadmap — العقل الإداريّ لمنظمة لغة ص

> **الإصدار:** v0.1 (تأسيس) — 2026-06-21
> **النوع:** مستودع حوكمة فيدراليّ (لا كود منتج).
> **القاعدة الذهبيّة:** هذا هو المستودع **الوحيد** الذي يزوره أيّ مطوّر/وكيل **قبل** بدء أيّ مهمة.

---

## ما هذا المستودع؟

`sadlang-roadmap` هو **الطبقة الفيدراليّة على مستوى المنظمة**: مصدر حقيقة واحد يوحّد كل
مستودعات لغة ص (المترجم، المفسّر، الأدوات، الإضافات، الذكاء، الوثائق) تحت:

1. **مراحل (Phases)** — ترتيب صارم لتطوّر المنظومة (`phases/`).
2. **معالم (Milestones)** — أهداف كبرى عابرة للمستودعات، لكلٍّ تاريخ ومسؤول و DoD (`milestones/`).
3. **مهامّ (Tasks)** — فهرسة المهام الصغيرة وربطها بمرحلة + معلم + مستودع + مسؤول (`tasks/`).
4. **فِرَق (Teams)** — من يملك أيّ مستودع (`teams/`).
5. **حالة (Status)** — لوحة Kanban وملفّ حالة آليّ (`status/`).
6. **حوكمة منع التشتّت** — القواعد الصارمة ([GOVERNANCE.md](GOVERNANCE.md)).

---

## ⚠️ المبدأ المعماريّ: فيدراليّ لا مكرِّر (Single Source of Truth)

لغة ص تملك بالفعل نظام إدارة ناضجًا داخل
[`s-programming-language/_bmad-output/`](https://github.com/sadlang/s-programming-language)
(إطار **PMF**، أنظمة بقصص و ADRs وجداول أدلّة، استراتيجية المنتجات الثلاثة) ونظام
**RFC** في [`sadlang-rfcs`](https://github.com/sadlang/sadlang-rfcs).

> **`sadlang-roadmap` لا ينسخ هذه المهام. يفهرسها ويوجّه إليها.**
> حقيقة كل مهمة تبقى في مستودعها (قصّة / RFC / ستوري). الخارطة تحمل **مؤشّرات + تجميعًا
> على مستوى المنظمة** فقط. هذا يمنع التباعد (drift) — وهو أخطر ما يهدّد نظامًا متعدّد المستودعات.

هذا تطبيق مباشر لقاعدة **GR-01** في PMF: *لا ادّعاء بلا دليل، ومصدر حقيقة واحد لكل معلومة.*

## الخريطة الذهنيّة

```
الرؤية ──► مرحلة (Phase) ──► معلم (Milestone) ──► مهمّة (Task) ──► قصّة/RFC في مستودع المنتج
 (ROADMAP)     (phases/)        (milestones/)        (tasks/)            (مصدر الحقيقة)
```

## الهيكل

```
sadlang-roadmap/
├── ROADMAP.md            # العرض الرئيسيّ: المراحل + الموضع الحاليّ + تجميع المعالم
├── CONTRIBUTING.md       # البوّابة الإلزاميّة قبل أيّ مهمة
├── GOVERNANCE.md         # قواعد منع التشتّت (Anti-Chaos)
├── phases/               # المراحل 0..5 (ترتيب صارم)
├── milestones/           # المعالم العابرة للمستودعات (+ قالب)
├── tasks/                # فهرسة المهام (+ قالب) — مؤشّرات لا نسخ
├── teams/                # الفِرَق ↔ المستودعات (teams.yaml)
├── status/               # kanban.md + roadmap-status.yaml (آليّ)
├── schema/               # مخطّطات التحقّق (phase/milestone/task/team)
└── scripts/              # validate_roadmap.py (مدقّق الاتّساق)
```
