# المرحلة 3 — بيئة التطوير

> **الحالة:** 🟡 بدأت · **المعلم:** [إضافة VS Code 1.0](../milestones/M-vscode-1.0.md)

## الهدف
تجربة تطوير كاملة: محرّر غنيّ بدعم RTL، تنقيح، REPL، قياس أداء.

> **قرار مالك (2026-06-21):** إضافات VS Code **ثلاثة منتجات متمايزة** لا نسخ مكرّرة:
> `vs_code_rtl` (محرّر RTL) · `arabic_vscode` (حزمة تعريب) · `vscode-extension` (تنفيذ سحابيّ، مرحلة 4).
