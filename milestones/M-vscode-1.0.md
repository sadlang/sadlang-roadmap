# 🎯 إضافة VS Code 1.0

> **المرحلة:** 3 · **الحالة:** 🟡 جارٍ · **التاريخ:** Q1 2027 · **المسؤول:** فريق المحرّر
> **المستودع:** `vs_code_rtl` (نمط Strategy، نقطة التسجيل `buildRegistry()`).

## المعنى
إضافة VS Code ناضجة بدعم RTL كامل للغة ص، تتكامل مع LSP والمنقّح.

## معيار الإنجاز (DoD)
- [ ] إبراز الصياغة (Syntax Highlighting).
- [ ] القصاصات (Snippets).
- [ ] الأوامر (Commands).
- [ ] لوحة RTL (RTL Panel).
- [ ] مستكشف AST (AST Explorer).
- [ ] تكامل المنقّح (Debugger Integration).

## شرط مسبق

- [ ] بوّابة المرحلة 2 مُجتازة.
